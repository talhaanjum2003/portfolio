MOTIONFORGE

A motion graphics engine that writes its own animation code. Template tools make video fast and make everything look the same — I wanted the speed without the sameness.

An AI art director picks palette, typography, background system, camera moves and transitions from a script and a niche. One sentence becomes one scene. Upload a voiceover and Whisper snaps every scene to the actual speech.

The decision I'd defend: the model doesn't write rendering code in the default path. It emits a validated JSON spec and a hand-built Remotion engine renders it — which is why any single scene can be regenerated without breaking the other nine. A second mode breaks that rule on purpose: a local Qwen3-Coder writes a real component per scene inside a sandbox with no network, no eval, and no non-determinism, because Remotion renders frames out of order.
